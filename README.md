# C Programming Assignment

A structured collection of C programming assignment work, including platform question documents and standalone programs. Files were copied from the supplied source assignment; existing source content and filenames were preserved.

## Repository structure

- `Platform_Questions/` — platform-specific DOCX assignments, with a pending screenshot marker and URL marker for each question.
- `VSCode_Questions/C_Programs/` — standalone C sources from both assignment sets and the VS Code question bank.
- `VSCode_Questions/Documentation/` — reserved for VS Code assignment documentation.
- `Assignment_Reports/` — inventory and validation report.

## Compilation

Requires GCC. From the repository root, compile an individual program with:

```sh
gcc "VSCode_Questions/C_Programs/Assignment_1/Q1.c" -o program
./program
```

On Windows, run `program.exe` after compilation. Compile each source separately because these files contain independent `main` functions.
