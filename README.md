# FOCP-1 C Programming Assignment

A collection of C programming solutions and supporting assignment documents for the FOCP-1 course.

## Repository layout

- `VSCode_Questions/C_Programs/` contains the C solutions, grouped by assignment where applicable.
- `Platform_Questions/` contains platform problem documents, source links, and submission evidence status notes.

## Contents

This repository includes 37 C source files and 30 DOCX assignment documents. Markdown files provide the repository overview, problem URLs, and notes about submission evidence. Any evidence status notes describe pending screenshots; no screenshots or submission evidence have been fabricated.

## Compile a C program

Compile a selected source file with GCC from the repository root, for example:

```sh
gcc -std=c11 -Wall -Wextra VSCode_Questions/C_Programs/Q1.c -o q1
```

Each source file is a separate exercise and should be compiled individually. Some exercises may require platform specific input or may have diagnostics that are documented during review.
